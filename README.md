# Panggil / نداء — Digital Coaster Pager Platform

> Zero-hardware digital coaster pager and smart menu system for restaurants & cafes.
> Production-ready on Next.js 15, TypeScript, Tailwind CSS, Supabase Realtime, and Web APIs.

## 🌐 Live Domain
- **Production URL:** [https://panggil.adhamnur.site](https://panggil.adhamnur.site)
- **Local Dev:** `http://localhost:3014`

## 🚀 Features
- **Zero-Hardware Coaster Pager:** Web Audio API synth buzzer alarms, HTML5 vibration patterns, Web Speech API voice synthesis.
- **Screen Wake Lock API:** Keeps smartphone screen awake during food preparation.
- **Dual Modes:** Pager Only vs Digital Menu + Pager.
- **Tri-Lingual Support:** Bahasa Indonesia (Default), Arabic (Full RTL), and English (LTR).
- **Thermal Invoice Engine:** Printable 80mm receipts with dynamic QR code.
